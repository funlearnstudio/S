## Documentation rules

To keep the documentation consistent:

1. New user-facing source uses `.se`, not legacy `.s`.
2. Commands use `se`.
3. Stable release instructions and future design documents are kept separate.
4. Examples should be runnable against the implementation they document.
5. English and Traditional Chinese primary guides should have matching structure and terminology.
